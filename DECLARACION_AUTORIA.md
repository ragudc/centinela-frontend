## 1. Declaración de autoría

Yo, Roberto Agudelo, declaro que soy el autor y responsable del desarrollo del presente
proyecto de software, **Centinela Dental — Frontend** (`centinela-frontend`), la aplicación web
(Next.js) que consume el backend federado del proyecto para mostrar el catálogo de productos, el
panel de escalaciones, la captura de leads y el asistente de chat en vivo de un distribuidor
dental ficticio.

El desarrollo se realizó bajo mi dirección, con **asistencia de herramientas de inteligencia
artificial** — específicamente **Claude Code** (Anthropic, modelo Claude Sonnet 5) — utilizada
como asistente de programación (pair programming) durante el diseño de la interfaz, la
implementación de componentes, la depuración de errores (incluyendo comportamiento de layout y
scroll), y la documentación técnica.

El uso de esta herramienta no exime mi responsabilidad como autor: todas las decisiones de
diseño, los requisitos funcionales, las correcciones aplicadas y el resultado final fueron
definidos, revisados y validados por mí. El código generado con asistencia de IA fue leído,
comprendido y aprobado antes de su incorporación al proyecto.

## 3. Aceptación de términos de uso

Declaro haber leído y aceptado los términos de uso de los servicios y dependencias de terceros
integrados en este proyecto, incluyendo, entre otros:

- **Términos de Servicio de Anthropic** (uso de Claude Code durante el desarrollo).
- Las licencias de código abierto de las dependencias declaradas en `package.json` (Next.js,
  React, Radix/Base UI, Tailwind, lucide-react, entre otras).

Todo el contenido mostrado en la interfaz (textos de marca, copys, imágenes de producto de
relleno) es original o de uso responsable para fines de este proyecto — no fue extraído ni
hotlinkeado desde sitios reales de terceros.

## 4. Alcance y limitaciones

Este es un proyecto de desarrollo/demostración que consume el backend de `centinela-backend`. No
representa una empresa real ni constituye software listo para producción sin las revisiones de
seguridad, accesibilidad y rendimiento correspondientes. El asistente de chat que consume desde
esta interfaz puede operar en modo simulado o mediante niveles gratuitos de proveedores de IA
durante el desarrollo, según se documenta en el backend del proyecto.
